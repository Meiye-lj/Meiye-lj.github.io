## Ongoing Projects

### Systematic Acceleration of Complex Software Builds

**NSFC Young Scientists Fund · 2027–2029**

This project investigates systematic performance bottlenecks in complex software builds
and develops acceleration techniques across three complementary levels:

- **Cross-configuration reuse** — characterize reuse boundaries and ordering sensitivity
  across build configurations.
- **Waiting loss and parallelism** — identify unnecessary waiting and resource
  under-utilization within individual builds.
- **Critical paths and acceleration bounds** — analyze long dependency chains and
  estimate the attainable upper bound of build acceleration.


---

### Trustworthy Execution of Autonomous Software R&D

**Ongoing Research Program**

This project studies how autonomous software engineering agents can execute development
tasks reliably and efficiently in real software environments.

Current topics include:

- task–behavior–state–evidence modeling;
- efficient execution under correctness constraints;
- failure diagnosis, attribution, and recovery;
- adaptive human intervention and autonomy control.
